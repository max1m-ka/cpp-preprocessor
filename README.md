# C++ Preprocessor

Учебная реализация препроцессора `#include` на C++.

## О проекте

Программа читает исходный файл, находит директивы `#include` и рекурсивно подставляет содержимое подключаемых файлов в выходной файл.

Поддерживаются два варианта подключения:

- `#include "file.h"` — сначала поиск относительно текущего файла;
- `#include <file.h>` — поиск в переданных каталогах включаемых файлов.

При невозможности найти файл программа сообщает об ошибке с указанием подключаемого файла, исходного файла и номера строки.

## Технологии

- C++17
- `<filesystem>`
- `<fstream>`
- `<regex>`
- `<optional>`
- рекурсивная обработка файлов

## Тестирование

В `main()` запускается набор проверок, который создаёт тестовую структуру каталогов и файлов, выполняет препроцессинг и сравнивает результат с ожидаемым содержимым с помощью `assert`.

## Сборка

Для сборки требуется компилятор с поддержкой C++17.

Пример:

```bash
g++ -std=c++17 main -o preprocessor
./preprocessor
```

## Цель проекта

Проект выполнен в рамках обучения C++ и предназначен для практики работы с файловой системой, потоками, регулярными выражениями, `std::optional` и рекурсивной обработкой данных.
